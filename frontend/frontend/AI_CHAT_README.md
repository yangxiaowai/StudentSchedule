# AI对话功能使用说明

## 功能概述

本系统集成了基于SSE（Server-Sent Events）的AI对话功能，为学生提供智能学习助手服务。

## 主要特性

### 🤖 智能对话
- 实时流式响应，提供流畅的对话体验
- 支持学习规划、问题解答、进度分析等多种场景
- 基于上下文的连续对话能力

### 💬 用户界面
- 现代化的聊天界面设计
- 支持Markdown格式渲染
- 响应式设计，适配移动端和桌面端
- 实时打字指示器和加载状态

### 🔧 技术特性
- 基于SSE的实时流式数据传输
- 自动会话管理和历史记录
- 错误处理和重连机制
- 安全的Token认证

## 使用方法

### 1. 访问AI对话
- 登录系统后，点击顶部导航栏的 "AI Chat" 按钮
- 或直接访问 `/ai-chat` 路径

### 2. 开始对话
- 在输入框中输入您的问题或需求
- 按Enter键发送消息（Shift+Enter换行）
- AI助手将实时流式回复您的问题

### 3. 会话管理
- **新建会话**：点击右上角"新建会话"按钮
- **清空对话**：点击"清空对话"按钮删除当前会话历史
- 系统会自动为每个会话生成唯一ID

## 技术实现细节

### 前端组件结构
```
src/
├── components/
│   └── AIChat.vue          # 核心对话组件
├── pages/
│   └── AIChat.vue          # AI对话页面
└── api/
    └── config.js           # API配置
```

### SSE连接流程
1. 用户发送消息到 `/api/chat/stream` 接口
2. 后端建立SSE连接，返回流式数据
3. 前端实时接收并渲染AI回复
4. 连接结束后更新UI状态

### 数据格式
```javascript
// 请求格式
{
  "sessionId": "uuid",
  "message": "用户输入的消息"
}

// SSE响应格式
data: {"content": "AI回复内容片段", "done": false}
data: {"content": "", "done": true}
```

## 配置说明

### 后端配置
- 确保 `ChatController` 正确配置SSE接口
- 检查CORS设置允许前端域名访问
- 验证Token认证机制正常工作

### 前端配置
- API基础URL：`http://localhost:8081`
- 自动Token注入和错误处理
- 响应式设计适配

## 故障排除

### 常见问题

1. **连接失败**
   - 检查后端服务是否启动（端口8081）
   - 验证网络连接和防火墙设置
   - 确认Token是否有效

2. **消息发送失败**
   - 检查请求格式是否正确
   - 验证用户认证状态
   - 查看浏览器控制台错误信息

3. **流式响应中断**
   - 检查网络稳定性
   - 验证SSE连接是否正常建立
   - 查看后端日志排查问题

### 调试技巧
- 打开浏览器开发者工具查看Network面板
- 检查Console面板的错误信息
- 使用后端日志分析请求处理过程
